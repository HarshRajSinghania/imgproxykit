imgproxykit
===========

A typed Python toolkit for building imgproxy URLs.
Define immutable image transformations and generate signed URLs or reference
presets configured on your imgproxy server.

Installation
------------

Requires Python 3.12 or newer::

    pip install imgproxykit

See the `GitHub repository <https://github.com/kondratevdev/imgproxykit>`_
for the quick-start example, contribution guide, and issue tracker.
